# 2026 年 11 月 天象参照数据（北京时间 UTC+8）

> **用途**：独立于本机 `astronomy-engine` 引擎的**外部参照值**，用于交叉验证「天象预报 2026年11月」生成结果。
> **时区**：表中「北京」列一律为 **UTC+8**；「源值」列保留来源原始时区，便于追溯。
> **换算规则**：`北京时间 = UTC + 8 小时`（AstroPixels GMT 页、天文通 API 的 `Z` 时间戳按此换算；NAOJ 为 JST−1h）。**逐条整数小时加减，未插值、未平均**。
> 标注 **`*`** 的事件表示**来源只给到小时**（`hh:00`），分钟不可信，比对应放宽（APX 自述整点事件精度 ±30 min）。
> 标注 **`未获取`** 的表示确实取不到，并写明原因。
